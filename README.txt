LIBRARY MANAGEMENT SYSTEM
==========================

Technology:
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

HOW TO RUN
----------

1. Open Command Prompt in this project folder.

2. Install Flask:
   pip install -r requirements.txt

3. Run the project:
   python app.py

4. Open this address in your browser:
   http://127.0.0.1:5000

The database file "library.db" will be created automatically when the project is started.

MAIN FEATURES
-------------
- Add and delete books
- Add and delete students
- Search books
- Issue books
- Return books
- Automatic fine calculation
- Dashboard statistics
- Issue and return history

FINE RULE
---------
Students can keep a book for 14 days.
After 14 days, fine is Rs. 2 per extra day.
